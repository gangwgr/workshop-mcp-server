Cursor Integration

Use this MCP server from Cursor IDE and use Cursor Agent models from the web UI.

1. Cursor IDE → MCP Server

Add this to .cursor/mcp.json in this repo (already included) or your global ~/.cursor/mcp.json:

{{ mcp_config }}

Restart Cursor. Then ask: "Analyze must-gather at /path/to/bundle" or "Debug my apiserver pods" — Cursor will call your MCP tools.

2. Cursor IDE Slash Commands

Custom commands live in .cursor/commands/. Type / in Cursor chat:

{% for cmd in cursor_commands %} {% endfor %}
CommandDescription
{{ cmd.usage }}{{ cmd.description }}

3. Web UI → Cursor Agent Models

  1. Get API key from cursor.com/dashboard/integrations
  2. Settings → Cursor Agent → paste CURSOR_API_KEY
  3. Top nav → select Cursor Agent and model (e.g. composer-2.5)
  4. Run Must-Gather or Cluster Debugger — LLM analysis uses Cursor SDK

With CURSOR_ATTACH_MCP=true, the Cursor agent can also call your workshop MCP tools during analysis.
