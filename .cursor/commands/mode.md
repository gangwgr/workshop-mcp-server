# Switch LLM mode

Use the `switch_llm_mode` MCP tool.

Request: $ARGUMENTS

Examples:
- `cursor composer-2.5` → mode=cursor, model=composer-2.5
- `ollama llama3.3:latest`
- `claude`
- `template`

Supported modes: `ollama`, `claude`, `cursor`, `template`

Confirm the new mode and model after switching.
